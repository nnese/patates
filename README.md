# Patates Soyucu

Tarayıcıda çalışan 1. şahıs patates soyma oyunu (Three.js).

## Çalıştırma

```bash
python -m http.server 8765
```

Tarayıcı: [http://localhost:8765](http://localhost:8765)

## Kontroller

| Tuş | İşlev |
|-----|--------|
| WASD | Yürü |
| Shift | Koş |
| Fare | Bakış (hassasiyet menüden) |
| E / Sol tık | Patates al / koy / suya at |
| F | Bırak |
| Q | Bıçak |
| R | Patatesi döndür |
| Esc / M | Menü |
| H / ? | Kılavuz |

## Akış

Yığından al → sol rafa koy → ortaya yerleştir → `%100` soy → alıp **su kanalına** at → **+$0.20**

Türler: Russet, Kırmızı, Yukon Gold, Tatlı patates, Mor — her birinin kendi şekli ve rengi vardır.
